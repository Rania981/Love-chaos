# 💕 Love Chaos

**Love Chaos** is a playful web application designed to bring couples closer through laughter, fun, and meaningful moments. Instead of focusing on productivity or social networking, Love Chaos creates a lighthearted space where every click leads to a new surprise.

Explore hilarious relationship roasts, random truth or dare questions, romantic fortunes, date ideas, mini challenges, and sweet compliments—all wrapped in a modern, animated, and cozy interface.

Whether you're spending time together in person or connecting from afar, Love Chaos is all about creating smiles, sharing laughs, and making everyday moments a little more memorable.

## ✨ Features

* ❤️ Random Love Fortunes
* 😂 Funny Couple Roasts
* 🎲 Truth or Dare
* 🎁 Random Love Button
* 🎡 Date Idea Wheel
* 🍕 Who's Paying Today?
* 💌 Cute Compliments & Messages
* ✨ Beautiful Animations & Interactive UI
* 📱 Fully Responsive Design
* 🌙 Light & Dark Mode

## 🛠️ Built With

* React
* TypeScript
* Tailwind CSS
* Framer Motion
* Lucide React
* Vite

**Love Chaos** isn't about winning—it's about laughing together, making memories, and adding a little chaos to love. 💕
